# Click-1000 ✦

لعبة نقر (Clicker) عربية بسيطة تعمل مباشرة في المتصفح، بدون تثبيت أو خادم.

## طريقة اللعب
- اضغط على البلورة البنفسجية لجمع العملات.
- اشترِ **نقرة أقوى** لزيادة عدد العملات التي تحصل عليها في كل ضغطة.
- اشترِ **نقر تلقائي** للحصول على عملات كل ثانية.
- كل 100 نقرة ترفع مستواك.
- تقدمك يُحفظ تلقائيًا في المتصفح.

## التشغيل
افتح `index.html` في المتصفح، أو انشر الملفات باستخدام GitHub Pages.

## الملفات
- `index.html` — بنية الواجهة.
- `style.css` — التصميم المتجاوب.
- `game.js` — منطق اللعب والترقيات والحفظ.

## ملاحظات
- لا يحتاج المشروع إلى مكتبات JavaScript خارجية.
- خط Changa يُحمّل من Google Fonts، ويستخدم المتصفح خطًا بديلًا إذا لم يتوفر الاتصال.
- الحفظ محلي على نفس المتصفح والجهاز.
